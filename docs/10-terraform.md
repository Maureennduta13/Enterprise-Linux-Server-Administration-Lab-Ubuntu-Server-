# Module 10: Infrastructure as Code with Terraform

## Objective
Move from manually clicking through VirtualBox to provision a VM, to
defining that same infrastructure as code — the practice that underpins
real-world cloud engineering.

## Prerequisites
- Comfortable with the full lab so far (Modules 1-9)
- A cloud provider free-tier account (AWS, GCP, or Azure)

## Planned Steps (fill in once you reach this module)

### 1. Install Terraform

### 2. Write a basic Terraform config
Define a single cloud VM (e.g. an AWS EC2 t2.micro on the free tier) as code.

### 3. Plan and apply
```bash
terraform init
terraform plan
terraform apply
```

### 4. Tear down and recreate
```bash
terraform destroy
```
